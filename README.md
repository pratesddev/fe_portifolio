## 📋 Sobre o projeto

Projeto desenvolvido para apresentação de um portfólio de um desenvolvedor ou empresa no formato SPA. O projeto é desenvolvido em HTML e CSS, sem nenhum tipo de interatividade (JavaScript). A ideia é estudar sobre layout e customização via CSS.

### Objetivo

Estudar HTML e CSS aplicando técnicas de desenvolvimento e estruturação funcionais.

### Funcionalidades

- [x] Header sempre visivel;
- [x] Navegação por links
